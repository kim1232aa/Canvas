## 1 名字行字号
根因：`src/index.css` L50 `.canvas-node label, input, select, textarea { font-size:.875rem; line-height:1.5 }` 是非 layer 的 CSS，压过 Tailwind v4 的 `text-xs` 工具类（utilities 在 @layer 里）。所以 select 实际是 14px，`<p>` 名字行不在这条规则内，仍是 text-xs 12px。12/14≈86%，加上等宽字体视觉差，就是重拍看到的约 80%。
改：`node-video-model-label` → `text-[0.875rem] leading-[1.5] font-mono`，与 select 实际计算值一致。

## 2 长 ID 断行
- 新增 `src/utils/softBreaks.ts`：显示值在每个 `/`、`-` 后插 U+200B（textarea 里不能用 wbr），所以断行发生在 `/`、`-` 之后，符号留在行尾。
- 所有读取路径都去掉 U+200B：onChange、Enter、blur、onCopy/onCut 改写剪贴板；光标用 logicalCaret/displayCaret 映射后复原。提交和存储的值不变（单测往返验证）。
- textarea 样式 `word-break:normal overflow-wrap:anywhere hyphens:none`，去掉 line-break:loose。
