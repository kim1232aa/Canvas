## 1) 同一次选模型+运行，schema GET 只能 1 条

**Root cause.**  
`App.tsx` called `beginSharedGetAction()` at both run starts (graph + spatial). Selecting a model already bumped the sharedGet epoch and issued one Schema GET via `noteUserModelSelection`. Starting a run bumped the epoch again, so the driver's `sharedGetJson` treated it as a new action and fetched a second time (clean-1005 shot 06: extra `GET …/model-schema?…krea-v2/turbo-lora` 200 after run click).

**Fix.**  
- Removed `beginSharedGetAction()` from both run paths in `App.tsx`. Select-model + run share one action; the driver reuses the memo (success or failure).  
- Comments in `sharedGet.ts` updated: a new action is model (re)selection / force refresh, not run start.  
- Re-selecting a model still calls `noteUserModelSelection` → one new GET. Mount/hydrate still 0.

**Tests.** `src/utils/clean1005.test.tsx` §1:  
- `noteUserModelSelection` then `SchemaProviderDriver.generate` → exactly 1 Schema GET.  
- Failure shared: same rejected result, still 1 GET.  
- Control: calling `beginSharedGetAction` (old run behaviour) would fetch again.

**Files:** `src/App.tsx`, `src/services/sharedGet.ts`, `src/utils/clean1005.test.tsx`.

## 3) 拖动对齐时连线 10→9：误删边

**Root cause.**  
SVG wires used `onClick={() => onDeleteConnection(conn.id)}` with a wide transparent hit area (`strokeWidth={18}`). After reconnecting 加载底模 MODEL → LoRA model (10 edges), the tester dragged nodes to align them. Clicking near the new wire’s approach to the LoRA socket (outside the node box, where the hit-area sticks out) deleted that edge → 9. Outcome.json: “Status line changed from '10 条连线' … to '9 条连线' after the node moves”.

**Fix.**  
- Wire delete is **double-click only** (`onDoubleClick`); single click only `stopPropagation`.  
- Ignore double-clicks that moved >6px (drag-like).  
- Hover title: 「双击删除连线」.  
- Nodes remain `z-20` above wires `z-10` (unchanged).

**Tests.** clean1005 §3: Canvas source asserts double-click path, no single-click delete.

**Files:** `src/components/Canvas.tsx`, `src/utils/clean1005.test.tsx`.
