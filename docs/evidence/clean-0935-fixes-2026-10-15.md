## 1 + 2. Schema GET, badges and Schema fields before any user action
**Root cause A: the Schema GET on load.** `ApiParameterEditor` used a "mounted" ref and skipped only the first effect run. `main.tsx` renders under `<StrictMode>`, so in dev the effect runs twice on mount. The second run looked like a change and fetched once per Checkpoint node. That is the `GET /api/model-schema?...z-image/turbo` row seen after the hard refresh. My unit tests called functions directly and never went through StrictMode or the real mount.

**Fix A.** The editor keeps a ref with the previous `{scope, epoch}`. It fetches only when both of these hold:
- the provider or model differs from the previous value, and
- a user action began since then (`ProviderModelSelect.onChange` → `beginSharedGetAction()`).

The initial value, hydrate and StrictMode re-runs now only peek at results already fetched.

**Root cause B: 会发送 badges before any action.** `rescopeCustomParameters` saves the Schema property list into the node's `custom_parameters._canvas.schemaProperties`. The workspace cache stored it, and `withCachedSchemaProperties` treated it as explicit, so Empty Latent height and KSampler seed showed 会发送 straight from the previous session's Schema.

**Fix B.** `resetRunState`, which runs on workspace restore, strips the Schema-derived `_canvas` keys:
- schemaProperties, schemaConfirmedFields, schemaUnprobed
- schemaUnavailable, schemaLoading, hasReferenceImage

User JSON and user flags are kept.

**Audit of other load-time fetches.**
- `ProviderModelSelect` is armed only by focus, typing, 刷新目录 or a provider change.
- The badge cache (`ensureModelSchema`) never fetches.
- `CivitaiModal` and `ModelHubModal` effects are guarded by `isOpen`.
- `NodeItem`, `ParameterInspector` and `Canvas` make no fetch calls.
- App effects: only `fetchHistory`, which is local history, not a Schema or catalog call.

**Files:** `src/components/ApiParameterEditor.tsx`, `src/utils/workspaceCache.ts` (adds `stripDerivedSchema`).

## 4. Earlier images after a refresh
- **Root cause:** the restore kept `outputData` with no provenance.
- **Fix:**
  - `resetRunState` marks nodes that have an output with `restoredFromPreviousSession: {at}`, where `at` is `outputAt` if recorded. Nothing is deleted.
  - `App.tsx` records `outputAt` when a run delivers output, and clears the mark when this session runs.
  - The `NodeItem` preview block (KSampler, VAEDecode, SaveImage and others) shows 「刷新前的结果 · <time> · 不是本次会话生成」, or 「刷新前的结果（时间未记录）…」 when no time was recorded.
- Outputs saved before this change have no time recorded.
- **Files:** `src/utils/workspaceCache.ts`, `src/App.tsx`, `src/types/graph.ts`, `src/components/NodeItem.tsx` (`restoredOutputLabel`).
