## 用到的官方端点
| 用途 | 端点 |
|---|---|
| 模型中心目录 | `GET https://api.aimlapi.com/v1/models?include=modalities,capabilities`（过滤 image/video） |
| LoRA 中心 | **无独立权重目录**；LoRA 节点粘贴 HF `owner/repo` 或 URL → `loras[].path` |
| 图像生成 | `POST https://api.aimlapi.com/v1/images/generations`（**同步** `data[].url` / `b64_json`） |
| 视频生成 | `POST https://api.aimlapi.com/v2/video/generations` → `id` |
| 视频轮询 | `GET https://api.aimlapi.com/v2/video/generations?generation_id=`，status ∈ queued/generating/completed/error（示例另见 waiting/succeeded） |
| Key 测试 | `GET https://api.aimlapi.com/v2/billing` |
| 余额 | `GET /v2/billing` → `current_balance` / `currency` |

## LoRA：官方能力
| 模型 | LoRA | 字段 |
|---|---|---|
| `alibaba/z-image-turbo-lora` | 是 | `loras[{path,scale}]` max 3；scale **0–4**，**无默认** |
| `blackforestlabs/flux-2-lora` | 是 | 同上 |
| 其它无 `loras` 的图像模型 | 否 | 挂 LoRA → **400**，不静默剥离 |
| 视频（如 Pixverse V5.5 i2v） | 否 | Schema 无 loras |

付费冒烟 **必须带真实 LoRA**（本集成已做到）：path=`ostris/z_image_turbo_childrens_drawings`（官方文档示例 HF），scale=`0.85`。
