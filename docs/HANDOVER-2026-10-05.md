## 1. 五条铁律（用户定的，不可协商）

1. **调查与断言原则**：任何 API/库事实先调查（web 搜索、官方文档、真实请求），严禁凭记忆断言。
2. **严禁静默容灾与虚假成功**：不得偷偷换供应商/端点/模型；错误必须原样透传（HTTP 状态码 + 响应体 + stack）。
3. **严禁 Fallback 掩盖错误**。
4. **严禁硬编码集成**：动态配置，通用 API Schema 驱动。
5. **严禁黑盒**：所有调用流、参数转换必须可见可追溯（前端「执行记录」面板 + 服务端 `logs/upstream.log`）。

## 2. 验收标准（用户原话的落地解释）

- 绿勾/测试通过/构建通过**都不是**验收标准，**前端跑通出图才是**。
- 能生成的供应商**必须真实出图**，且：带参数（seed/steps/size 等）、带工作流快照（workflowSnapshot）、带 LoRA 参数（符合该端点真实能力）。
- 底模中心 / LoRA 中心 / 节点下拉框的模型必须来自**实时目录**，数量与官方一致，可刷新，无硬编码清单。
- 欠费不算失败（记 PASS_BILLING）；环境不通记 BLOCKED_ENV；凭证无效记 BLOCKED_AUTH。
- 判定等级（HANDOFF.md §3.1）：`PASS_GENERATION / PASS_BILLING / BLOCKED_AUTH / BLOCKED_ENV / FAIL_INTEGRATION / NOT_TESTED`。

## 4. 环境与运行

### 4.1 硬要求
- **Node 22**（undici 8 依赖；Node 20 不行）。沙箱里没有就解 `/mnt/agents/node22.tar.xz`（已缓存）。
- 安装依赖：`npm install`；启动：`npx tsx server.ts`（或 `npm run dev`），监听 127.0.0.1:3000。
- 验证命令：`npx tsc --noEmit` / `npx vitest run` / `npm run build`。

### 4.2 网络与代理
- GitHub / huggingface.co / civitai.com 直连经常不通。用 mihomo（安装包在 `/mnt/agents/mihari-all-in-one-linux-amd64.tar.gz`）：
  1. 解出 `data/bin/mihomo` 与 `data/geoip/*`，把 `GeoLite2-Country.mmdb` 复制为 `Country.mmdb` 和 `geoip.metadb`（否则卡在 MMDB 下载）。
  2. 配置用 **proxy-providers + 订阅 URL**（订阅地址在 `/mnt/agents/canvas-keys.env` 的 `MIHOMO_SUB_URL`），mixed-port 7890、external-controller 9090、mode: global。
  3. 启动后 GLOBAL 默认 DIRECT——**必须手动选节点**：`curl -X PUT 127.0.0.1:9090/proxies/GLOBAL -d '{"name":"TimeIs·time.is"}'`（该节点实测可用；节点列表 `curl 127.0.0.1:9090/proxies`）。
  4. git/curl 走代理：`git -c http.proxy=http://127.0.0.1:7890 ...`。
  5. **server.ts 必须在启动时带 `HTTPS_PROXY=http://127.0.0.1:7890`（和 `HTTP_PROXY`、`NO_PROXY=127.0.0.1,localhost`）**，否则 EnvHttpProxyAgent 不生效，Civitai/HF 上游全部超时。这是第 5 次清空后实测确认的硬性前提。
  6. 另有 13 个 SOCKS5 备选（`/mnt/agents/socks5-list.txt`），订阅失效时逐个试。

### 4.3 密钥管理（红线：永不进 git/截图/日志）

## 5. 浏览器自动化验收方法（browser-harness，替代 Playwright/jev）

Playwright 太慢、jev-ultrafast 在此应用上不可用（请求体 78KB 超 TEXT_MODEL max_tokens，已弃用）。当前有效方案：

- 安装：`pip install browser-harness`；通过 CDP 驱动已有 Chromium：`BU_CDP_URL=http://127.0.0.1:9222 browser-harness <<'PY' ... PY`。
- 可用助手：`js(expr)`、`click_at_xy(x,y)`、`fill_input(selector, text)`（对 React 受控输入安全：真实键盘事件逐字符）、`capture_screenshot(path)`、`new_tab/list_tabs/switch_tab/close_tab(id)`、`wait_for_element`、`cdp(domain.method, session_id=...)`。
- **关键 DOM 事实**（实测，勿猜）：
  - 画布节点 class 是 `.canvas-node`（**不是** `.react-flow__node`）。
  - 底模中心自定义模型输入框 `#custom-tensor-template-input-modelhub`；Fal/LoRA 自定义输入框用 `input[placeholder*='fal-ai']`、`input[placeholder*='LoRA path']` 定位。
  - API 参数 JSON 框 `textarea[aria-label="自定义 API 参数 JSON"]`。
  - 清空受控 textarea 要用原生 setter：`Object.getOwnPropertyDescriptor(HTMLTextAreaElement.prototype,'value').set.call(ta,'{}'); ta.dispatchEvent(new Event('input',{bubbles:true}))`。
  - 屏外元素先 `scrollIntoView()` 再 JS `.click()`；`alert()` 会卡死截图，用 CDP `Page.handleJavaScriptDialog` 处理。
  - **「清空画布」「重置为默认工作流」菜单项走原生 `confirm()`，CDP 下静默不弹窗导致点击无效——先执行 `window.confirm = () => true` 再点。**
  - 执行记录条目的展开钮是 `<summary>`（details/summary 结构）。
- 画布状态持久在浏览器 profile 的 localStorage（`comfycanvas_boards_v2` 等），刷新不丢。**清空画布的最可靠方式**：直接改 `comfycanvas_boards_v2`（nodes/connections 置空）后 `location.reload()`。
- 沙箱浏览器以 `--proxy-server=10.86.13.73:5900` 启动（系统代理，出网能力有限）；浏览器直连不通的域名（HF/Civitai）都让请求走服务端路由，由带代理的 server.ts 转发。

## 6. 沙箱易失性运维教训（本轮 5 次重置换来）

1. **/tmp 随时清空**：代码、node_modules、Node22、证据截图都会没。对策：
   - 仓库放 `/mnt/agents/work/Canvas`（持久）；每个验收完成**立即 commit push**。
   - 密钥/订阅/SOCKS 列表/Node22 安装包放 `/mnt/agents/`（已落地）。
2. **pkill 自杀陷阱**：`pkill -f "tsx server.ts"` 会匹配到自己所在的 shell 命令行。用脚本文件包一层，且循环里排除 `$$`/`$PPID`。
3. **mihomo 全局默认 DIRECT**：不选节点等于没代理。
4. **Vite/esbuild 僵尸**：服务被异常杀死后再启动可能出现「转换出空模块」（页面白屏、报 export 缺失）——重启 dev server 解决。
5. **server.ts 代理必须启动时注入**（§4.2-5），中途改环境变量无效。

### 6.4 第 5 次清空后的恢复手册（按序执行，全程约 5 分钟）

```sh
pip install browser-harness                       # CDP 驱动
mkdir -p /tmp && tar -xf /mnt/agents/node22.tar.xz -C /tmp   # Node22
cp -r /mnt/agents/work/Canvas /tmp/Canvas         # 运行副本（master 即最新推送态）
cd /tmp/Canvas && export PATH=/tmp/node-v22.21.1-linux-x64/bin:$PATH
export HTTPS_PROXY=http://127.0.0.1:7890 HTTP_PROXY=http://127.0.0.1:7890
npm install --no-audit --no-fund                  # 需 mihomo 已在跑
# mihomo:
mkdir -p /tmp/mihomo && tar -xzf /mnt/agents/mihari-all-in-one-linux-amd64.tar.gz -C /tmp/mihomo
cd /tmp/mihomo && cp data/GeoLite2-Country.mmdb data/Country.mmdb
# 写 config-mini.yaml（proxy-providers 订阅，mixed-port 7890，external-controller 9090，mode global）
nohup ./data/bin/mihomo -d . -f config-mini.yaml &
curl -X PUT 127.0.0.1:9090/proxies/GLOBAL -d '{"name":"TimeIs·time.is"}'
# 起服务（用脚本文件防 pkill 自杀；必须带代理 env 与密钥 env）
```

浏览器（系统 Chromium，9222 端口）不受 /tmp 清空影响，画布 localStorage 在浏览器 profile 里，恢复后无需重建画布。
